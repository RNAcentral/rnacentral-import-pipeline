
===================================================================
RNAcentral Species-Specific Sequences (by-species/)
===================================================================

This directory contains active RNAcentral sequences split into one FASTA
file per species, organised into subdirectories by kingdom (bacteria/,
archaea/, viruses/, plants/, fungi/, vertebrates/, metazoa/, protists/,
environmental/), e.g. vertebrates/homo_sapiens.fasta.gz.

environmental/ holds entries that aren't a real taxon at all, such as
metagenome samples (e.g. air metagenome, activated sludge metagenome) or
other unclassified/synthetic NCBI entries.

* What's included
To keep this directory a manageable size, only species with at least 100
active sequences are split into their own file. Species with fewer than
100 sequences are not split out individually, but can still be looked up
in rnacentral_species_specific_ids.fasta.gz.
